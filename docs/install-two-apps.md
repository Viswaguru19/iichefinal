# Install IIChE and IIChE Chat separately

The portal and chat are separate installable apps:

| App | Open this page | Launches |
| --- | --- | --- |
| IIChE | `/dashboard` | Portal, events, forms, tasks, and workflows |
| IIChE Chat | `/chat` | Direct messages, groups, files, polls, and voice messages |

## Upgrade from the older combined install

The older IIChE install used one app scope for the whole site. Remove that existing home-screen app once before installing the new pair. This does not delete your account or portal data.

## Android (Chrome or Edge)

1. Open `/dashboard`, sign in, open the browser menu, and choose **Install app**. Confirm the name **IIChE**.
2. Open `/chat`, open the browser menu, and choose **Install app** again. Confirm the name **IIChE Chat**.
3. Check the home screen for two icons. The Chat icon has a teal chat badge.

## iPhone or iPad (Safari)

1. Open `/dashboard`, tap **Share**, then **Add to Home Screen**. Keep the name **IIChE**.
2. Open `/chat`, tap **Share**, then **Add to Home Screen**. Keep the name **IIChE Chat**.
3. Check the home screen for both apps.

## Verify

- Opening **IIChE** starts at `/dashboard`.
- Opening **IIChE Chat** starts at `/chat`.
- Installing one app does not make the other page report that it is already installed.

If the second install still says “already installed,” remove the old combined IIChE app, close and reopen the browser, then repeat the two install steps.
